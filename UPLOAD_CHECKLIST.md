# Publication Checklist

## Included

- EPPM implementation and three primary configurations.
- English README, framework graphic, environment specifications, and usage.
- Dataset format, verified checksums, and separate data archive instructions.
- Original reference metrics, result collector, and CPU tests.
- Anonymous citation metadata and third-party source notices.

## Before Upload

- Confirm upstream code redistribution and attribution requirements.
- Confirm redistribution permission for all three datasets independently.
- Resolve the documented historical evaluation-window difference against the
  manuscript before describing the artifact as fully manuscript-aligned.
- Inspect the files in a fresh extraction of the code archive.
- Keep checkpoints, private notes, credentials, and experiment logs out of Git.
- Use an anonymous account and inspect commit author name and email.
- Avoid personal links, identifying repository history, and identifying release
  metadata during anonymous review.
- Publish the data archive separately only when its redistribution is allowed.
- Add the actual download location to the README once it exists.

Code publication does not include the datasets or checkpoints. No code license
or dataset redistribution permission is inferred from the packaging.
